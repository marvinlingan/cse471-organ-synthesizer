Project 1: Hammond-Style Organ Synthesizer

Individual CSE 471 project

Selection

Four-Chord Study — 64 seconds, 120 BPM, 32 measures.

Score file

Download XML score. Each note has measure, beat, duration in beats, and pitch. The sequencer schedules notes and mixes all active voices one frame at a time.

Organ synthesis

The organ voice sums nine sine-wave components using Hammond drawbar frequency ratios 1, 3, 2, 4, 6, 8, 10, 12, and 16. Drawbar positions map to 3 dB amplitude increments. Notes use short attack and release ramps. Vibrato changes oscillator frequency; a stereo Leslie-style modulation changes channel amplitude.

Effects

The effects class includes a delay-based reverberation approximation, chorus, flanging, and sinusoidal ring modulation. Delay buffers persist between sample frames and do not store the entire song.

Note: The included reference WAV demonstrates echo/reverb only. Build and render the Visual Studio implementation to demonstrate all effects.

Streaming

Each call to CSynthesizer::Generate() creates one stereo sample frame. Active notes are held as individual voices, not a full-song sample buffer.

Files

Source is provided in the project ZIP. Generated audio is 44,100 Hz, 16-bit stereo.
